# Kiln & Code

Official Kiln & Code website.

## Repository structure

- `index.html` — production homepage
- `assets/styles.css` — production site styles
- `assets/*-concept.png` — concept/demo images used on the Kiln & Code site
- `favicon.svg` — browser icon
- `robots.txt` / `sitemap.xml` — search-engine discovery
- `thanks.html` — enquiry-form confirmation page
- `client-template/` — reusable starter for client websites

## Editing rules

- Keep business contact details and pricing consistent with the sales system.
- Concept work must remain clearly labelled as demo/concept work until replaced by genuine client work.
- Do not expose private credentials or API keys in this repository.
- Test the production deployment after changing `main`.
