# Kiln & Code client site starter

Use this folder as the starting point for a new client website.

## Workflow

1. Copy `client-template/` into a new client repository.
2. Replace every `{{PLACEHOLDER}}` in `index.html`.
3. Add only client-supplied or properly licensed project images under `assets/`.
4. Check mobile layout, phone/email links, spelling, service areas and factual claims.
5. Add the client's privacy/cookie information if forms, analytics or third-party embeds are used.
6. Connect the client's domain only after written approval.
7. Keep the Kiln & Code sales site and client repositories separate.

## Required launch checks

- Contact details tested
- No demo testimonials presented as real
- Images have permission to be used
- Page title and meta description set
- Canonical URL set
- Mobile check complete
- HTTPS/domain working
- Client approval recorded
